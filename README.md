# ReversePitch 🚀
### Let Companies Discover You Through Your Work

ReversePitch is a project-based talent discovery platform designed to help companies discover developers based on the projects they have built, the technologies they use, and the features they have implemented.

Instead of relying only on resumes and listed skills, ReversePitch aims to help recruiters explore real projects, GitHub repositories, and live demos to better understand a developer's practical abilities.

## 🎯 Problem Statement

Traditional recruitment often relies heavily on resumes, degrees, and self-reported skills. It can be difficult for recruiters to verify a candidate's practical experience quickly.

ReversePitch aims to bridge this gap by making developers' projects searchable and easier to evaluate.

## 💡 Our Solution

ReversePitch will provide a platform where:

- Developers can create profiles and showcase their projects.
- Projects can be discovered by technology, category, and implemented features.
- Recruiters can explore project details, GitHub repositories, and live demos.
- Companies can shortlist promising developers and send hiring or interview invitations.

## ✨ Planned Features

### 👨‍💻 For Developers
- User registration and login
- Developer profile management
- Create, edit, and delete projects
- Add project descriptions and technology stacks
- Include GitHub repository and live demo links
- Showcase implemented features
- Receive hiring and interview invitations

### 🏢 For Recruiters
- Company profile management
- Search projects by technology and category
- Filter projects by implemented features
- Explore developer profiles
- Shortlist potential candidates
- Send hiring or interview invitations
